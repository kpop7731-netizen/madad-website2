# موقع مِداد | الشاب المسلم

الصفحة الرئيسية للمنتج + صفحة الحجز، جاهزتين للنشر على GitHub Pages.

## هيكل الملفات

```
midad/
├── index.html      ← الصفحة الرئيسية (القصة، المحتوى، الفيديو، الحجز)
├── booking.html    ← صفحة الحجز المباشر عبر واتساب
├── assets/         ← مجلد فاضي جاهز للوجو والصور لما تجهز
└── README.md
```

## خطوات النشر على GitHub Pages (٥-١٠ دقايق)

1. روح على [github.com](https://github.com) وسجّل دخول (أو اعمل حساب لو معندكش)
2. دوس **New repository** (الزرار الأخضر)
3. اكتب اسم المستودع: `midad`
4. خليه **Public** (لازم يكون Public عشان GitHub Pages تشتغل مجانًا)
5. **متحطش** علامة "Add a README file" (عندنا واحد جاهز)
6. دوس **Create repository**
7. في الصفحة اللي هتفتح، دوس على **uploading an existing file**
8. اسحب الملفات التلاتة (`index.html`, `booking.html`, `README.md`) ومجلد `assets` كله هنا
9. دوس **Commit changes** تحت الصفحة
10. روح لـ **Settings** (في المستودع نفسه) → **Pages** (في القائمة الجانبية شمال)
11. تحت **Branch**، اختار `main` والمجلد `/ (root)`، ودوس **Save**
12. استنى ١-٢ دقيقة، وحدّث الصفحة — هيظهرلك رابط شكله:
    ```
    https://<اسم-حسابك>.github.io/midad/
    ```
13. افتح الرابط ده — الموقع لازم يكون شغال

## تحديث اللوجو لاحقًا

لو حابب تستبدل الووردمارك النصي بلوجو PNG:
1. حط ملف اللوجو في مجلد `assets/` باسم `logo.png`
2. في `index.html`، دور على السطر:
   ```html
   <div class="brand">مِداد</div>
   ```
   واستبدله بـ:
   ```html
   <img src="assets/logo.png" alt="مداد" style="height:34px;">
   ```

## ربط فيديو اليوتيوب لاحقًا

في `index.html`، دور على قسم الفيديو (فيه تعليق `<!-- ... -->` يوضح مكانه بالظبط)، واستبدل سطر "الفيديو قريبًا…" بكود الـiframe المذكور في التعليق، وحط رقم الفيديو الحقيقي بدل `VIDEO_ID`.

## تحديث عدد النسخ المتبقية

في `booking.html`، دور على السطر:
```js
const REMAINING_COPIES = 50;
```
وغيّر الرقم يدويًا كل ما تتراكم حجوزات. **ملحوظة:** العدّاد هنا ثابت مش حي/متزامن تلقائيًا (كان ده متاح بس جوه بيئة Claude)، فلازم تحدّثه بنفسك بين كل فترة والتانية.

## ملاحظة عن الروابط الاجتماعية

في `index.html`، أسفل الصفحة (Footer)، فيه روابط لإنستجرام ويوتيوب حاليًا بعلامة `#` (يعني مش مربوطة بحاجة). عدّلها بروابط حساباتك الفعلية أول ما تنشر.
